Iris Flower Classification 🌸

📌 Project Overview

This project uses Machine Learning to classify Iris flowers into different species based on their sepal and petal measurements.

🎯 Objective

To build a machine learning model that predicts the species of an Iris flower using its features.

🛠️ Technologies Used

- Python
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

📊 Dataset

The Iris dataset contains measurements of three flower species:

- Setosa
- Versicolor
- Virginica

📁 Project Files

- "iris_classification.py" — Python source code for flower classification.
- "iris_classification_matrix.jpeg" — Classification matrix image.

🚀 How to Run

1. Install Python.
2. Install the required libraries:
   "pip install pandas numpy matplotlib scikit-learn"
3. Run the program:
   "python iris_classification.py"

📈 Results

The model classifies Iris flowers based on their measurements. The classification matrix image is included in this repository.
